Data Driven Nutritional Analysis & Visualization Framework

A machine learning-based framework for analyzing, visualizing, and predicting nutritional patterns from food datasets using Data Analytics, Exploratory Data Analysis (EDA), and classification models.

📌 Project Overview

This project focuses on analyzing nutritional datasets containing attributes like calories, proteins, fats, carbohydrates, and fiber. The framework performs:

Data preprocessing and cleaning
Feature engineering
Exploratory Data Analysis (EDA)
Nutritional data visualization
Machine Learning model training
Calorie category prediction

The system classifies food items into:

Low Calorie
Medium Calorie
High Calorie

based on nutritional values.

🚀 Features
Nutritional data preprocessing
Outlier handling using IQR method
Correlation heatmaps and visual analytics
Feature engineering for nutrient ratios
Machine learning classification models
Model comparison and evaluation dashboard
Prediction module for calorie classification
